## Logo retenu — décision (2026-06-30)
**`logo-tikmos-dark-gold.jpeg`** est le logo principal : il incarne la charte **« Encre + Or
champagne »** (or = luxe + prestige ; marine = expertise data/IA ; silhouette qui s'élève =
transmission). Le **marine du logo = `indigo` (#1e2a52)** de la charte.

### À produire pour la prod (le JPEG fourni ne suffit pas)
- **Version vectorielle SVG** (`logo-tikmos-lockup.svg` + `logo-tikmos-mark.svg`) — netteté + perf.
- **Fond transparent**, deux variantes :
  - **claire** (marine + or) pour header sur ivoire/blanc,
  - **inversée** (blanc/or) pour le **footer encre** et fonds sombres.
- Favicon / icônes app (mark seul) en plusieurs tailles + maskable (si PWA).
